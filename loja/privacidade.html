Os teus dados

Política de privacidade

A tua privacidade é importante para nós. Esta página explica, de forma simples, como tratamos os teus dados quando usas a Roque Digital.

Que dados recolhemos

  • Nome, contacto e morada, para processar e entregar a tua encomenda
  • Histórico de encomendas e favoritos, para melhorar a tua experiência

Como usamos os teus dados

Usamos os teus dados apenas para processar encomendas, comunicar contigo sobre o estado da tua compra e melhorar o nosso serviço. Nunca vendemos os teus dados a terceiros.

Os teus direitos

Podes, a qualquer momento, pedir para consultar, corrigir ou apagar os teus dados, entrando em contacto connosco pelo WhatsApp ou email.
